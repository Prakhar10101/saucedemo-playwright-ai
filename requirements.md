Feature 1: Login

- A user can log in with a valid username and password.
- A locked-out user sees an error and cannot log in.
- Empty username or password shows a validation error.

Feature 2: Product list

- Products can be sorted by name (A-Z, Z-A) and price (low-high, high-low).

Feature 3: Cart

- A user can add a product to the cart and the cart badge shows the count.
- A user can remove a product from the cart.

Feature 4: Checkout

- A user must enter first name, last name and postal code.
- A completed order shows a confirmation message
